## 10. 完整页面间跳转图

```
App Start
  ├─ 未登录 → /auth/login
  │            ├─ 登录成功 → /(tabs)/friends  (首次跳好友引导加好友)
  │            ├─ 去注册 → /auth/register → /(tabs)
  │            └─ 仅本地使用 → /(tabs)
  │
  └─ 已登录 → /(tabs)
                ├─ 今日 (index)
                ├─ 日记
                ├─ 好友 (friends)
                │    ├─ 待处理角标 → /friend/requests
                │    ├─ 搜索/添加 → /friend/search
                │    │              ├─ 扫码 → /friend/qrcode
                │    │              └─ 搜索结果 → sendRequest
                │    └─ 好友卡片 → /friend/[id]
                │
                └─ 我的 (profile)
                     ├─ 二维码加好友 → /friend/qrcode
                     ├─ 我的好友 (N) → /(tabs)/friends
                     └─ 账号设置 → /settings/account
                                     ├─ 修改昵称
                                     └─ 退出登录 → /(auth)/login
```

## 11. 移动端适配要点

| 设备 | 适配 |
|---|---|
| iPhone (安全区) | SafeAreaView + bottom tab 现有 paddingBottom 逻辑复用 |
| Android (虚拟键) | 同上 |
| Web | 现有 maxWidth: 600 居中即可；登录页单独加 minHeight: 100vh |

---

## 12. 无障碍 & 微交互

- 所有 Pressable 加 `accessibilityRole="button"` + `accessibilityLabel`。
- 加油按钮按下时 scale 动画 1.0 → 0.95 → 1.0（react-native Animated）。
- 数字加载用 skeleton（背景灰块淡入）。
- 错误提示走顶部 banner（不打断操作流）。
